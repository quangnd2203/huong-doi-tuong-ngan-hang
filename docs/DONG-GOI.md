# Đóng gói nộp đồ án

Theo slide 20, dùng tên `OOP_Nhom05_QuanLyNganHang.zip`, thư mục bên trong cùng tên bỏ đuôi `.zip`. Số 05 lấy từ nhóm đăng ký 5 trong ảnh.

| Sản phẩm | Trạng thái hiện tại | Việc cần làm trước khi nộp |
| --- | --- | --- |
| README.md | Có hướng dẫn cho khung hiện tại | Cập nhật cách chạy ứng dụng hoàn chỉnh và link GitHub |
| BAO-CAO.pdf | Chưa có | Hoàn thiện tài liệu `bao-cao/`, xuất PDF 10–20 trang ở gốc gói nộp |
| PHAN-CONG.xlsx | Chưa có | Chuyển nội dung PHAN-CONG.md thành XLSX |
| uml/class-diagram.png | Đã có ảnh cũ, không khớp Mermaid hiện tại | Hoàn thiện UML và xuất lại sơ đồ PNG khớp mã nguồn |
| src/ | Có điểm chạy và các thư mục | Hoàn thiện mã nguồn |
| data/ | Có hướng dẫn | Thêm dữ liệu mẫu giả lập, thử đọc lại |
| demo.mp4 | Tùy chọn, chưa có | Video 3–5 phút nếu thực hiện |
| Link GitHub | Chưa có | Tạo repo, đẩy mã và kiểm tra quyền truy cập |

Trước khi nộp, giải nén vào thư mục mới, làm theo README, kiểm tra build/chạy, dữ liệu mẫu và đủ các file bắt buộc. Bỏ thư mục build, cấu hình IDE và file tạm khỏi ZIP.
